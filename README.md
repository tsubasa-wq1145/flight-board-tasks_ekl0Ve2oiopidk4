# 🛫 DEPARTURE — Flight Board Task List

空港の反転フラップ式案内表示機（Solari Board）をモチーフにした、シングルHTMLのタスク管理アプリ。
飛行機好きのための実用ツールとして自作。

---

## 概要

- タスクを「出発便」に見立てて、空港の発車標風ボードに一覧表示する
- 外部依存ゼロの単一HTMLファイル（`index.html`）で完結
- データはブラウザの `localStorage` に保存（サーバー不要、端末内に保持）
- GitHub Pages でホスティング → iPhone の「ホーム画面に追加」でアプリ風に起動

## 公開URL / 環境

- 公開先: GitHub Pages（`https://<ユーザー名>.github.io/flight-board-tasks/`）
- iOS: Safari で開いて「ホーム画面に追加」するとフルスクリーン起動（メタタグ対応済み）
- ⚠️ データは URL（ドメイン）に紐づく。リポジトリ名やホスト先を変えると別物扱いになり、タスクは引き継がれない

---

## 項目の対応（案内表示機 ↔ タスク）

| ボードの列 | 英字 | タスクの項目 |
|---|---|---|
| カテゴリ | AIRLINE | カテゴリ（航空会社欄に見立て） |
| タスク名 | DESTINATION | タスク名（行き先） |
| 開始 | DEPART | 開始タイミング（日付・時間） |
| 期限 | ARRIVE | 終了期限（日付・時間） |
| 優先 | GATE | 優先度（搭乗口番号風に 1 / 2 / 3） |
| 備考 | REMARKS | 備考 / 状況 |

## 機能

- **タスク入力**: 「＋ タスク入力」ボタンでモーダル表示。カテゴリ・タスク名・開始・期限・優先度・備考を入力
- **並び順**: 終了期限が近い順に自動ソート
- **優先度**: 搭乗口番号風に `1 = 低 / 2 = 中 / 3 = 高`。数字の色も変化（1=青系 / 2=アンバー / 3=赤）
- **完了機能**: ✓ ボタンで完了 → 非表示。トグルで完了タスクの表示/非表示を切り替え
- **編集 / 削除**: ✎ で編集、🗑 で削除（削除時は確認あり）
- **DELAYED 表示**: 期限超過したタスクは備考欄が赤い「DELAYED 遅延」表示になり点滅。ボードを開いたまま期限を過ぎても30秒ごとに自動チェックして切り替わる
- **カテゴリ色分け**: 「仕事」= ANAブルー / 「プライベート」= JALレッド の背景。色変更はカテゴリ欄のみ
- **カテゴリ追加**: モーダル内の「＋」から自由に追加可能（初期値: 仕事 / プライベート / 買い物 / 健康 / スポッティング）
- **時計**: 右上にリアルタイム時計

## 実装メモ

- 単一 `index.html`。CSS / JS すべて内包、外部ライブラリなし（フォントのみ Google Fonts を `@import`）
- 保存キー: タスク = `flightBoardTasks_v1` / カテゴリ = `flightBoardCats_v1`
  - データ構造を将来変える場合は `_v2` のように採番してマイグレーション方針を決める
- 各タスクの `id` は `Date.now()` + ランダム文字列で生成
- フラップ風の見た目は CSS グラデーション（上下で色を変えて中央に分割線）で表現。実際のフリップ動作（パタパタ）は無し＝静的表示
- iOS アプリ化用メタタグ: `apple-mobile-web-app-capable` ほかを `<head>` に設定済み

## 更新手順

1. ローカルで `index.html` を編集
2. リポジトリで同名ファイルを上書きアップロード（コミット）
3. 数分後に GitHub Pages へ自動反映
