# 🛫 DEPARTURE — Flight Board Task List

空港の反転フラップ式案内表示機（Solari Board）をモチーフにした、シングルHTMLのタスク管理アプリ。
飛行機好きのための実用ツールとして自作。

-----

## 概要

- タスクを「出発便」に見立てて、空港の発車標風ボードに一覧表示する
- 外部依存ゼロの単一HTMLファイル（`index.html`）で完結
- データはブラウザの `localStorage` に保存（サーバー不要、端末内に保持）
- GitHub Pages でホスティング → iPhone の「ホーム画面に追加」でアプリ風に起動

## 公開URL / 環境

- 公開先: GitHub Pages（`https://<ユーザー名>.github.io/flight-board-tasks/`）
- iOS: Safari で開いて「ホーム画面に追加」するとフルスクリーン起動（メタタグ対応済み）
- ⚠️ データは URL（ドメイン）に紐づく。リポジトリ名やホスト先を変えると別物扱いになり、タスクは引き継がれない

-----

## 項目の対応（案内表示機 ↔ タスク）

|ボードの列|英字         |タスクの項目                |
|-----|-----------|----------------------|
|カテゴリ |AIRLINE    |カテゴリ（航空会社欄に見立て）       |
|タスク名 |DESTINATION|タスク名（行き先）             |
|開始   |DEPART     |開始タイミング（日付・時間）        |
|期限   |ARRIVE     |終了期限（日付・時間）           |
|優先   |GATE       |優先度（搭乗口番号風に 1 / 2 / 3）|

## 機能

- **タスク入力**: 「＋ タスク入力」ボタンでモーダル表示。カテゴリ・タスク名・開始・期限・優先度を入力
- **並び順**: 終了期限が近い順に自動ソート
- **優先度**: 搭乗口番号風に `1 = 低 / 2 = 中 / 3 = 高`。数字の色も変化（1=青系 / 2=アンバー / 3=赤）
- **完了機能**: ✓ ボタンで完了 → 非表示。トグルで完了タスクの表示/非表示を切り替え
- **編集 / 削除**: ✎ で編集、🗑 で削除（削除時は確認あり）
- **DELAYED 表示**: 期限超過したタスクは期限（ARRIVE）の時刻が赤く点滅。ボードを開いたまま期限を過ぎても30秒ごとに自動チェックして切り替わる
- **カテゴリ色分け**: 「仕事」= ANAブルー / 「プライベート」= JALレッド の背景。色変更はカテゴリ欄のみ
- **カテゴリ追加**: モーダル内の「＋」から自由に追加可能（初期値: 仕事 / プライベート / 買い物 / 健康 / スポッティング）
- **Markdown インポート**: 「📋 インポート」ボタンから Markdown テーブルを貼り付けて一括登録。「追加」「全置き換え」を選択可（全置き換えは確認ダイアログあり）。形式不正の行は理由付きでスキップ報告、正しい行のみ取り込み。Markdown 内の新カテゴリは自動登録
- **時計**: 右上にリアルタイム時計

-----

## Markdown インポート形式

「📋 インポート」ボタンから、以下の形式の Markdown テーブルを貼り付けて取り込む。

```markdown
| カテゴリ | タスク名 | 開始 | 期限 | 優先 |
|---|---|---|---|---|
| 仕事 | 見積書を提出する | 2026-06-10 09:00 | 2026-06-12 17:00 | 3 |
| プライベート | 歯医者の予約 | 2026-06-11 10:00 | 2026-06-11 10:30 | 中 |
| スポッティング | 羽田 第2展望デッキ | 2026-06-15 14:00 |  | 低 |
```

### ルール

- 列は左から **カテゴリ / タスク名 / 開始 / 期限 / 優先** の固定5列
- **日時は `YYYY-MM-DD HH:MM` 形式のみ**。日付だけ（`2026-06-10`）や日本語表記（`6/10 9:00`）はエラーで弾かれる
- **優先度は `1/2/3` または `高/中/低`** を認識（高=3 / 中=2 / 低=1）。未記入は 2（中）扱い
- タスク名以外は空欄可（開始・期限が未定なら空のままでOK）
- 1行目のヘッダーと2行目の区切り線（`|---|`）、空行は自動スキップ
- 形式不正の行はスキップし、理由を表示。正しい行だけ取り込まれる
- Markdown 内に未登録のカテゴリがあれば自動でカテゴリに追加される

### 取り込み方法

- **追加**: 現在のタスクに足す
- **全置き換え**: 現在のタスクを全削除してインポート分に置き換え（確認ダイアログあり）

## 実装メモ

- 単一 `index.html`。CSS / JS すべて内包、外部ライブラリなし（フォントのみ Google Fonts を `@import`）
- 保存キー: タスク = `flightBoardTasks_v1` / カテゴリ = `flightBoardCats_v1`
  - データ構造を将来変える場合は `_v2` のように採番してマイグレーション方針を決める
- 各タスクの `id` は `Date.now()` + ランダム文字列で生成
- フラップ風の見た目は CSS グラデーション（上下で色を変えて中央に分割線）で表現。実際のフリップ動作（パタパタ）は無し＝静的表示
- iOS アプリ化用メタタグ: `apple-mobile-web-app-capable` ほかを `<head>` に設定済み

## 更新手順

1. ローカルで `index.html` を編集
1. リポジトリで同名ファイルを上書きアップロード（コミット）
1. 数分後に GitHub Pages へ自動反映

## メモ

- localStorage 依存のため、ブラウザのデータ削除やプライベートブラウズでは消える点に注意
- バックアップが欲しくなったら、まずエクスポート機能を最優先で実装する
- 備考（REMARKS）列は使わなかったため削除済み。期限超過の演出は備考欄ではなく期限（ARRIVE）の時刻を赤く点滅させる方式に変更。旧データに残る `note` プロパティは読まれないだけで無害
